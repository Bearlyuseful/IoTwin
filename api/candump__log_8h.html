Detailed Description

Log file lines in the can-utils "candump -L" format.

(1700000000.123456) iotwin 123#DEADBEEF

Files written by can_monitor –log can be replayed with can_replay or canplayer (can-utils), and candump logs from a real bus can be replayed onto iotwin-bus. On input the timestamp and the interface are optional, so plain "123#DEAD" lines work too; empty lines and lines starting with '#' or ';' are skipped.
