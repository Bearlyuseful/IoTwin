Detailed Description

Linear AC network solver: modified nodal analysis with complex phasors.

Node 0 is the reference (earth). Elements:

  • admittance between two nodes,
  • ideal voltage source: V(a) - V(b) = value,
  • ideal current source: value flows from node a to node b through the source. The current of every element is reported in the direction a -> b.

A small conductance gmin from every node to earth keeps floating parts of the network (open breakers, unconnected terminals) solvable; it also models a very high insulation resistance.

Solvers: networks without ideal voltage sources (supplies as Norton equivalents, as libs/elsim builds them) are solved by nodal analysis with a sparse LDL^T factorization (el_sparse.h). The ordering is computed once per topology and the factorization reused as long as no value changes, so a step of an unchanged network is only a forward/back substitution. With voltage sources (or EL_SOLVER_DENSE) modified nodal analysis with dense Gaussian elimination and partial pivoting is used.

Portable C99 without C99 complex numbers (MSVC has no complex arithmetic), so the same sources compile with GCC, Clang and MSVC, also inside the Unreal visualizer (ADR 0008). After the first solution of a network size the solver does not allocate memory any more.
