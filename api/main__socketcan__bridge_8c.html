Detailed Description

socketcan_bridge: connects a Linux CAN interface (vcan0, can0, USB adapter) to iotwin-bus.

candump / cansend / real ECUs <-> can0 <-> socketcan_bridge <-TCP-> iotwin-bus

SocketCAN does not deliver a socket's own frames back to it (CAN_RAW_RECV_OWN_MSGS is off by default), so frames written by the bridge do not loop back.
