Detailed Description

Scenario scripts for can_scenario (see docs/dev/scenarios.md).

One step per line, '#' starts a comment:

name Lamp follows the wall switch send 200#01 put a frame on the bus expect 100#01 within 300 a matching frame must arrive (default 1000 ms) expect-not 100#01 for 500 no matching frame for 500 ms wait 200 let time pass (ms) bench ecu fault short on test bench command to node "ecu" (can_sim) bus drop 100 200 fault of the bus: drop | delay | silence | seed | clear uds ecu 190209 expect 59027F900111* UDS request (ecu, gateway or TX:RX ids) log any text printed while running

Frame patterns: "100#01" exact, "100#01*" payload starting with 01, "100#*" any payload, "100#XX01" XX = any byte, "100#R" remote frame. UDS expectations are hex bytes, "*" at the end allows more bytes; without "expect" a positive response is required.

Parsing is free of I/O so it is unit tested; main_can_scenario.c runs it.
