Detailed Description

ISO-TP (ISO 15765-2) transport protocol for classic CAN, normal addressing.

Transfers up to 4095 bytes over 8-byte CAN frames:

SF 0L dd dd dd dd dd dd dd single frame, L = 1..7 FF 1L LL dd dd dd dd dd dd first frame, 12-bit length 8..4095 CF 2N dd dd dd dd dd dd dd consecutive frame, N = sequence 1..15,0,... FC 3S BS ST flow control: S = 0 CTS / 1 WAIT / 2 OVFLW, BS = block size, ST = STmin

The link is driven from outside: hand every received frame to isotp_on_frame() and call isotp_poll() regularly with the current time. Portable C without heap use (host and firmware).
