Detailed Description

serial_bridge: connects an SLCAN adapter (e.g. the IoTwin STM32 gateway) to iotwin-bus.

SLCAN adapter <–serial--> serial_bridge <–TCP--> iotwin-bus <--> other nodes

Single threaded: the loop alternates between the serial port and the bus socket with short timeouts (works the same on Windows and Linux). Reconnects to both sides automatically.
