Detailed Description

Encoding and decoding of signals inside a CAN payload (DBC semantics).

Bit numbering follows the DBC convention: bit n is bit (n % 8) of byte (n / 8).

  • Intel (little endian, "@1"): start_bit is the least significant bit, the signal grows towards higher bit numbers.
  • Motorola (big endian, "@0"): start_bit is the most significant bit; less significant bits follow downwards in the byte and continue at bit 7 of the next byte ("sawtooth").

physical = raw * factor + offset. Portable C without heap use (also usable in firmware).
