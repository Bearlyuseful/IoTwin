Detailed Description

can_scenario: runs scenario scripts against the nodes on iotwin-bus.

can_scenario data/scenarios/light-demo/switch-controls-lamp.scn can_scenario -e "bus drop 20" -e "bus delay 30 10" (one-off steps)

Exit code 0 when every scenario passed, 1 otherwise; usable as test.
