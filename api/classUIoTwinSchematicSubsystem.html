Detailed Description

Loads the system description (data/systems/*.json) with its DBC files and the component database, follows the traffic of UIoTwinBusSubsystem and owns the 3D / schematic view switch.

Configure in DefaultGame.ini ([/Script/IoTwin.IoTwinSchematicSubsystem]) or per run with -IoTwinSystem=<file>, -IoTwinView=Schematic and -IoTwinSelectNode=<node id>.
