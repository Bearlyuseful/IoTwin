\doxysubsection{Detailed Description}
Small JSON reader (RFC 8259) for the engineering data in data/. 

Parses a whole document into a tree. Objects keep the order of their members; duplicate keys are kept (json\+\_\+get returns the first). Strings are UTF-\/8, \textbackslash{}u escapes incl. surrogate pairs are decoded. Nesting is limited to JSON\+\_\+\+MAX\+\_\+\+DEPTH. Host only (uses the heap).
