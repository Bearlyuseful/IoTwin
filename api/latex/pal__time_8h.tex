\doxysubsection{Detailed Description}
Platform abstraction for monotonic time and sleeping. 

On Linux the absolute sleep uses clock\+\_\+nanosleep(\+TIMER\+\_\+\+ABSTIME) on CLOCK\+\_\+\+MONOTONIC, which is what a PREEMPT\+\_\+\+RT system needs for drift-\/free cyclic execution. On Windows the functions are best effort (millisecond timer resolution, no real-\/time guarantees).
