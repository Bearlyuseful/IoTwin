\doxysubsection{Detailed Description}
Log file lines in the can-\/utils "{}candump -\/\+L"{} format. 

(1700000000.\+123456) iotwin 123\#\+DEADBEEF

Files written by can\+\_\+monitor --log can be replayed with can\+\_\+replay or canplayer (can-\/utils), and candump logs from a real bus can be replayed onto iotwin-\/bus. On input the timestamp and the interface are optional, so plain "{}123\#\+DEAD"{} lines work too; empty lines and lines starting with \textquotesingle{}\#\textquotesingle{} or \textquotesingle{};\textquotesingle{} are skipped.
