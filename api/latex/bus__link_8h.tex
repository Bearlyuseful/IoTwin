\doxysubsection{Detailed Description}
\doxylink{structClient}{Client} connection to iotwin-\/bus for tools (replay, scenarios). 

Wraps the TCP socket and the line framing\+: frames are parsed and handed to on\+\_\+frame, control answers ("{}!ok"{}, "{}!error ..."{}, "{}!status ..."{}) and test bench lines ("{}@..."{}) to on\+\_\+control. Single threaded.
