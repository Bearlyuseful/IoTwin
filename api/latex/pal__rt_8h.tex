\doxysubsection{Detailed Description}
Real-\/time setup of the calling thread. 

Linux (reference platform, ideally with a PREEMPT\+\_\+\+RT kernel)\+:
\begin{DoxyItemize}
\item SCHED\+\_\+\+FIFO with the requested priority (needs CAP\+\_\+\+SYS\+\_\+\+NICE or an rtprio limit)
\item CPU pinning via pthread\+\_\+setaffinity\+\_\+np
\item mlockall() to avoid page faults (needs CAP\+\_\+\+IPC\+\_\+\+LOCK or a memlock limit)
\end{DoxyItemize}

Windows\+: best effort only. Thread priority and affinity are raised/set, memory locking is not supported and there are no timing guarantees.
