\doxysubsection{Detailed Description}
UDS diagnostics of the simulated light ECU (see docs/dev/diagnostics.\+md). 

Addressing\+: requests on 0x7\+E0 (and functional 0x7\+DF), responses on 0x7\+E8.

Faults can be injected (console command "{}fault"{}); monitors turn them into DTCs the way a real ECU would\+:
\begin{DoxyItemize}
\item lamp output short to ground (B1001-\/11)\+: the ECU switches the output off,
\item lamp output open circuit (B1001-\/13)\+: only detectable while the lamp is on,
\item supply voltage low (B1002-\/16).
\end{DoxyItemize}

Free of I/O and threads, unit tested on the host.
