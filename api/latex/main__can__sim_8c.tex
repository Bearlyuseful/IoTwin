\doxysubsection{Detailed Description}
can\+\_\+sim\+: simulated light control ECU on the \doxylink{classIoTwin}{Io\+Twin} CAN bus. 

Threads\+:
\begin{DoxyItemize}
\item main thread\+: cyclic control loop (optionally real-\/time), owns the socket
\item console thread\+: reads commands from stdin (not real-\/time)
\end{DoxyItemize}

The control loop never blocks on the network while connected\+: it reads whatever arrived, runs the ECU step, sends the outputs and sleeps until the next absolute deadline.
