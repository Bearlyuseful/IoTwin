\doxysubsection{Detailed Description}
Connects the game to iotwin-\/bus and makes the CAN traffic available on the game thread. Configure in Default\+Game.\+ini (\mbox{[}/\+Script/\+Io\+Twin.Io\+Twin\+Bus\+Subsystem\mbox{]}) or per run with -\/Io\+Twin\+Bus\+Host=, -\/Io\+Twin\+Bus\+Port=, -\/Io\+Twin\+Bus\+Disabled.
