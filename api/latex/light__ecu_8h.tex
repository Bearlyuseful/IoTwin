\doxysubsection{Detailed Description}
Simulated light control unit (the demo ECU of can\+\_\+sim). 

Signals (see docs/dev/protocol.\+md)\+:
\begin{DoxyItemize}
\item 0x200 SWITCH\+\_\+\+STATE (input)\+: data\mbox{[}0\mbox{]} bit 0 = position of the wall switch
\item 0x100 LAMP\+\_\+\+CMD (output)\+: data\mbox{[}0\mbox{]} bit 0 = lamp relay closed (lamp on)
\end{DoxyItemize}

The ECU sets the lamp to the switch position, can blink the lamp on its own, and sends LAMP\+\_\+\+CMD on every change plus cyclically, so a node that joins the bus later learns the current state within one cycle.

The logic is free of I/O and time sources so it can be unit tested.
