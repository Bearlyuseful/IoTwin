\doxysubsection{Detailed Description}
uds\+\_\+client\+: UDS tester (ISO 14229 over ISO-\/\+TP) for nodes on iotwin-\/bus. 

One-\/shot\+: uds\+\_\+client scan uds\+\_\+client --target gateway read 0200 0201 uds\+\_\+client session extended + write 0103 012C Interactive\+: uds\+\_\+client (commands from stdin; Tester\+Present keeps a non-\/default session alive)

Single threaded except for the stdin reader in interactive mode\+: all bus traffic is handled by the main thread.
