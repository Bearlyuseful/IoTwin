\doxysubsection{Detailed Description}
An actor or component that contributes devices and conductors to the electrical simulation (ADR 0008). Unreal owns the topology, the simulator computes every electrical value\+:


\begin{DoxyItemize}
\item \doxylink{classIElectricalElement_a105c29291eb0200efd15d0b67c6e69ce}{Describe\+Electrical()} adds the element to the model when the subsystem (re)builds it, e.\+g. a load connected to its port, or a cable between its ends.
\item \doxylink{classIElectricalElement_a6bab038e29705a8fdac3960d7d2c229d}{Apply\+Electrical()} is called every frame with the newest results.
\end{DoxyItemize}

Ports (UElectrical\+Port\+Component) become junctions with the terminals L, N and PE automatically; wires between ports become short links unless an element describes them (Claim\+Wire).
