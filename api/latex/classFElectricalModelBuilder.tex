\doxysubsection{Detailed Description}
Collects devices, cables and conductors for an \doxylink{structElModel}{El\+Model} (libs/elsim). Ids are "{}$<$actor$>$.$<$part$>$"{}, limited to the characters and length the core accepts; every port is a junction with the terminals L, N and PE.
