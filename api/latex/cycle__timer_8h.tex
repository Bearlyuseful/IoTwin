\doxysubsection{Detailed Description}
Drift-\/free periodic execution with wake-\/up latency statistics. 

The timer sleeps until absolute deadlines (start + n \texorpdfstring{$\ast$}{*} period), so the cycle does not drift with the execution time of the loop body. The measured wake-\/up latency (actual wake-\/up minus deadline) is the usual figure of merit for real-\/time systems and makes the difference between a standard and a PREEMPT\+\_\+\+RT kernel visible.
