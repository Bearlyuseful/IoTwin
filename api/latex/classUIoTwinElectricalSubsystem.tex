\doxysubsection{Detailed Description}
Runs the electrical simulation core (libs/elsim) for the scene\+:


\begin{DoxyItemize}
\item builds the model from the scene (ports become junctions, \doxylink{classIElectricalElement}{IElectrical\+Element} actors and components add devices and cables) and rebuilds it when the wiring changes;
\item steps it in its own thread with a fixed time step (default 10 ms), independent of the frame rate;
\item takes the newest snapshot and the events every frame and hands them to the elements; commands (switch, dim, faults, reset) go the other way.
\end{DoxyItemize}

Unreal owns the topology, the simulator every electrical value. -\/Io\+Twin\+Electrical\+Disabled switches it off, -\/Io\+Twin\+Short\+Circuit\+After=\sout{ puts a short circuit on the first load after s seconds (smoke tests). }
