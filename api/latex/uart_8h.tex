\doxysubsection{Detailed Description}
Interrupt driven USART2 (ST-\/\+LINK virtual COM port) with ring buffers. 

RX\+: the ISR stores bytes in a ring buffer, the main loop reads them. TX\+: the main loop fills a ring buffer, the TXE interrupt drains it.
