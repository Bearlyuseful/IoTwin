\doxysubsection{Detailed Description}
Worker thread that keeps a TCP connection to iotwin-\/bus alive and exchanges newline-\/terminated text lines with it.


\begin{DoxyItemize}
\item Reconnects automatically while the bus is not reachable.
\item Incoming lines are queued for the game thread (Dequeue\+Line).
\item Outgoing lines are queued by the game thread (Enqueue\+Line) and dropped while disconnected -\/ like frames sent on an unconnected CAN node. 
\end{DoxyItemize}
