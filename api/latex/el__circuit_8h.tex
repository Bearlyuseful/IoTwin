\doxysubsection{Detailed Description}
Linear AC network solver\+: modified nodal analysis with complex phasors. 

Node 0 is the reference (earth). Elements\+:
\begin{DoxyItemize}
\item admittance between two nodes,
\item ideal voltage source\+: V(a) -\/ V(b) = value,
\item ideal current source\+: value flows from node a to node b through the source. The current of every element is reported in the direction a -\/\texorpdfstring{$>$}{>} b.
\end{DoxyItemize}

A small conductance gmin from every node to earth keeps floating parts of the network (open breakers, unconnected terminals) solvable; it also models a very high insulation resistance. Dense Gaussian elimination with partial pivoting.

Portable C99 without C99 complex numbers (MSVC has no complex arithmetic), so the same sources compile with GCC, Clang and MSVC, also inside the Unreal visualizer (ADR 0008). After the first solution of a network size the solver does not allocate memory any more.
