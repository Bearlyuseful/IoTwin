\doxysubsection{Detailed Description}
Splits a TCP byte stream into newline terminated lines. 

TCP has no message boundaries\+: one recv() can contain half a line or several lines. The reader buffers partial input, strips a trailing \textquotesingle{}\textbackslash{}r\textquotesingle{} ("{}\textbackslash{}r\textbackslash{}n"{} line endings) and skips empty lines. Lines longer than LINE\+\_\+\+READER\+\_\+\+MAX\+\_\+\+LINE -\/ 1 characters are dropped as a whole.
