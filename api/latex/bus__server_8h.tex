\doxysubsection{Detailed Description}
Virtual CAN bus over TCP. 

Every connected client (simulator, visualizer, test tool) is a node on the bus. A frame received from one node is validated, normalised and forwarded to all other nodes -\/ like a broadcast on a physical CAN bus. Invalid lines are counted and dropped. See docs/dev/protocol.\+md.

The server is single threaded\+: call \doxylink{bus__server_8h_af0c8b52525ef74ebf7f1ff95a6825277}{bus\+\_\+server\+\_\+poll()} in a loop. \doxylink{bus__server_8h_aa3f74a060dbfd568d4019369650e9bbb}{bus\+\_\+server\+\_\+port()}, \doxylink{bus__server_8h_a27404fa633d7ead7fbb20ed610fa78a5}{bus\+\_\+server\+\_\+client\+\_\+count()} and \doxylink{bus__server_8h_a070d80b79cad3620cb1b1819f1106a49}{bus\+\_\+server\+\_\+get\+\_\+stats()} may be called from other threads.
