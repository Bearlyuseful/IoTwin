\doxysubsection{Detailed Description}
\doxylink{structScenario}{Scenario} scripts for can\+\_\+scenario (see docs/dev/scenarios.\+md). 

One step per line, \textquotesingle{}\#\textquotesingle{} starts a comment\+:

name Lamp follows the wall switch send 200\#01 put a frame on the bus expect 100\#01 within 300 a matching frame must arrive (default 1000 ms) expect-\/not 100\#01 for 500 no matching frame for 500 ms wait 200 let time pass (ms) bench ecu fault short on test bench command to node "{}ecu"{} (can\+\_\+sim) bus drop 100 200 fault of the bus\+: drop \texorpdfstring{$\vert$}{|} delay \texorpdfstring{$\vert$}{|} silence \texorpdfstring{$\vert$}{|} seed \texorpdfstring{$\vert$}{|} clear uds ecu 190209 expect 59027F900111\texorpdfstring{$\ast$}{*} UDS request (ecu, gateway or TX\+:RX ids) log any text printed while running

Frame patterns\+: "{}100\#01"{} exact, "{}100\#01\texorpdfstring{$\ast$}{*}"{} payload starting with 01, "{}100\#\texorpdfstring{$\ast$}{*}"{} any payload, "{}100\#\+XX01"{} XX = any byte, "{}100\#\+R"{} remote frame. UDS expectations are hex bytes, "{}\texorpdfstring{$\ast$}{*}"{} at the end allows more bytes; without "{}expect"{} a positive response is required.

Parsing is free of I/O so it is unit tested; \doxylink{main__can__scenario_8c}{main\+\_\+can\+\_\+scenario.\+c} runs it.
