\doxysubsection{Detailed Description}
Thread-\/safe FIFO of CAN frames\+: the local view of a node on the bus. 

A node uses one \doxylink{structCanBus}{Can\+Bus} as mailbox, e.\+g. frames received from the network are queued here until the control loop processes them, or frames typed on the console wait here until the control loop sends them. Each instance has its own storage and lock, so a process can have several of them.
