\doxysubsection{Detailed Description}
Reader for the DBC subset needed to name CAN traffic. 

Supported\+: BO\+\_\+ (messages, extended ids via bit 31), SG\+\_\+ (signals incl. multiplexer "{}\+M"{} and multiplexed "{}m\+N"{} signals), VAL\+\_\+ (value descriptions). Everything else (BU\+\_\+, CM\+\_\+, BA\+\_\+, NS\+\_\+, ...) is skipped. Host only (heap).
