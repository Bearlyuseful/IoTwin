\doxysubsection{Detailed Description}
Loads an installation (a JSON file in data/installations) into an \doxylink{structElModel}{El\+Model}. 

Parameters of a device come from, in this order\+: the defaults of its type, the component it refers to (data/components, by id), and fields of the device itself. Parameter names are the ones of the component database\+:

rated\+\_\+current, magnetic\+\_\+trip\+\_\+multiple, thermal\+\_\+limit (breaker), melting\+\_\+i2t (fuse), rated\+\_\+residual\+\_\+current (rcd), rated\+\_\+power, rated\+\_\+voltage (load), contact\+\_\+resistance; supply\+: system (TN-\/S, TN-\/\+C-\/S, TT), voltage, frequency, loop\+\_\+impedance, earth\+\_\+electrode, source\+\_\+earth.

A breaker component may give its tripping characteristic as property "{}characteristic"{}\+: B (5 x In), C (10 x In) or D (20 x In).
