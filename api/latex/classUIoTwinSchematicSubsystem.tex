\doxysubsection{Detailed Description}
Loads the system description (data/systems/\texorpdfstring{$\ast$}{*}.json) with its DBC files and the component database, follows the traffic of \doxylink{classUIoTwinBusSubsystem}{UIo\+Twin\+Bus\+Subsystem} and owns the 3D / schematic view switch.

Configure in Default\+Game.\+ini (\mbox{[}/\+Script/\+Io\+Twin.Io\+Twin\+Schematic\+Subsystem\mbox{]}) or per run with -\/Io\+Twin\+System=$<$file$>$, -\/Io\+Twin\+View=Schematic and -\/Io\+Twin\+Select\+Node=$<$node id$>$.
