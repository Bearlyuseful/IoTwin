\doxysubsection{Detailed Description}
Sparse LDL\texorpdfstring{$^\wedge$}{\string^}T factorization of complex symmetric matrices (nodal admittance matrices). 

The nodal admittance matrix Y of a passive network (admittances between nodes, gmin to earth) is complex symmetric (Y = Y\texorpdfstring{$^\wedge$}{\string^}T) and its Hermitian part
\begin{DoxyItemize}
\item the conductance matrix -\/ is positive definite. Such a matrix has an LDL\texorpdfstring{$^\wedge$}{\string^}T factorization for every symmetric ordering without pivoting, so the ordering can be chosen for sparsity alone\+:
\begin{DoxyEnumerate}
\item \doxylink{el__sparse_8h_a69bb3d164136c18aea8eb5daaafae212}{el\+\_\+sparse\+\_\+analyze()}\+: minimum-\/degree ordering and the pattern of L (once per network topology),
\item \doxylink{el__sparse_8h_ac166edb9a19e9629b30f55ee3c65ff07}{el\+\_\+sparse\+\_\+factor()}\+: numeric factorization (when values change),
\item \doxylink{el__sparse_8h_af9265f5b1ba9de7bccb00179c2fbda67}{el\+\_\+sparse\+\_\+solve()}\+: forward/back substitution (every solution).
\end{DoxyEnumerate}
\end{DoxyItemize}

The effort grows with the fill of L, not with n\texorpdfstring{$^\wedge$}{\string^}3 as for dense elimination. Pivots whose real part is not positive (only possible through rounding in floating parts of the network, which are held by gmin alone) are replaced by a small positive value and counted.
