\doxysubsection{Detailed Description}
Unified Diagnostic Services (ISO 14229-\/1) server on top of ISO-\/\+TP. 

Supported services (requests without the transport header)\+:

10 ss Diagnostic\+Session\+Control default (01) and extended (03) session 11 rr ECUReset hard (01) and soft (03) reset via callback 14 gg gg gg Clear\+Diagnostic\+Information all DTCs (FFFFFF) or a single DTC 19 01 mm Read\+DTCInformation number of DTCs matching a status mask 19 02 mm DTCs matching a status mask 19 0A all supported DTCs 22 dd dd .. Read\+Data\+By\+Identifier up to UDS\+\_\+\+MAX\+\_\+\+DIDS\+\_\+\+PER\+\_\+\+REQUEST identifiers 2E dd dd .. Write\+Data\+By\+Identifier extended session only 3E 00 Tester\+Present keeps a non-\/default session alive

The suppress\+Pos\+Rsp\+Msg\+Indication\+Bit (0x80 in the sub-\/function) is honoured for 10, 11 and 3E. Requests arrive physically (request\+\_\+id, ISO-\/\+TP, up to UDS\+\_\+\+MAX\+\_\+\+REQUEST bytes) or functionally (functional\+\_\+id, single frames only); for functional requests the NRCs 11, 12, 31, 7E and 7F are not sent. Without a request for s3\+\_\+ms the server falls back to the default session.

Data identifiers and resets are handled by the application through callbacks; DTCs live in an array owned by the application and are updated with \doxylink{uds_8h_a548803cfa527f1a81527599814cb83d8}{uds\+\_\+dtc\+\_\+report()}. Portable C without heap use (host and firmware).
