\doxysubsection{Detailed Description}
Application logic of the \doxylink{classIoTwin}{Io\+Twin} CAN gateway firmware (hardware independent). 

The board is two things at once\+:
\begin{DoxyItemize}
\item an SLCAN adapter\+: frames from the serial link are sent on the CAN bus, frames received from CAN are reported on the serial link;
\item a small CAN node\+: the user button is a wall switch (SWITCH\+\_\+\+STATE 0x200) and the LED shows the lamp command (LAMP\+\_\+\+CMD 0x100).
\end{DoxyItemize}

In internal loopback mode the controller receives its own frames. They are matched against the transmitted ones and not reported a second time, so the virtual bus does not see echoes.

All hardware access goes through \doxylink{structGatewayIo}{Gateway\+Io}, so this file is unit tested on the host with fake I/O.
