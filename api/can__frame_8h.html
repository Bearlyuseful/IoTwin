Detailed Description

Message-level model of classic CAN frames and their text encoding.

The simulation works on the logical content of a frame (identifier, flags, payload) like SocketCAN does. Bit-level fields such as SOF, CRC, ACK or EOF are generated by real controllers and are not modelled.

Text encoding (subset of the can-utils cansend/candump "compact" format), one frame per line on the wire:

123#DEADBEEF standard frame, 3 hex digit identifier (<= 0x7FF) 1F334455#11 extended frame, 8 hex digit identifier (<= 0x1FFFFFFF) 123# frame without payload (DLC 0) 123#R remote transmission request, optional DLC: 123#R4 123#DE.AD.BE '.' separators between bytes are accepted on input

Output is always upper case without separators.
