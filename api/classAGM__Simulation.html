Detailed Description

Game mode of the IoTwin visualizer. Optionally builds the light demo at runtime (so it works in any map, no binary assets needed):

power source with CAN relay (0x100) –cable--> lamp, wall switch (0x200)

The scene is driven by can_sim through iotwin-bus.
