Detailed Description

Unified Diagnostic Services (ISO 14229-1) server on top of ISO-TP.

Supported services (requests without the transport header):

10 ss DiagnosticSessionControl default (01) and extended (03) session 11 rr ECUReset hard (01) and soft (03) reset via callback 14 gg gg gg ClearDiagnosticInformation all DTCs (FFFFFF) or a single DTC 19 01 mm ReadDTCInformation number of DTCs matching a status mask 19 02 mm DTCs matching a status mask 19 0A all supported DTCs 22 dd dd .. ReadDataByIdentifier up to UDS_MAX_DIDS_PER_REQUEST identifiers 2E dd dd .. WriteDataByIdentifier extended session only 3E 00 TesterPresent keeps a non-default session alive

The suppressPosRspMsgIndicationBit (0x80 in the sub-function) is honoured for 10, 11 and 3E. Requests arrive physically (request_id, ISO-TP, up to UDS_MAX_REQUEST bytes) or functionally (functional_id, single frames only); for functional requests the NRCs 11, 12, 31, 7E and 7F are not sent. Without a request for s3_ms the server falls back to the default session.

Data identifiers and resets are handled by the application through callbacks; DTCs live in an array owned by the application and are updated with uds_dtc_report(). Portable C without heap use (host and firmware).
