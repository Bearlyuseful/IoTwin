Detailed Description

Sparse LDL^T factorization of complex symmetric matrices (nodal admittance matrices).

The nodal admittance matrix Y of a passive network (admittances between nodes, gmin to earth) is complex symmetric (Y = Y^T) and its Hermitian part

  • the conductance matrix - is positive definite. Such a matrix has an LDL^T factorization for every symmetric ordering without pivoting, so the ordering can be chosen for sparsity alone:
    1. el_sparse_analyze(): minimum-degree ordering and the pattern of L (once per network topology),
    2. el_sparse_factor(): numeric factorization (when values change),
    3. el_sparse_solve(): forward/back substitution (every solution).

The effort grows with the fill of L, not with n^3 as for dense elimination. Pivots whose real part is not positive (only possible through rounding in floating parts of the network, which are held by gmin alone) are replaced by a small positive value and counted.
