Detailed Description

Register level driver for FDCAN1 of the STM32G0B1 in classic CAN mode.

Message RAM (fixed layout on STM32G0/G4, 212 words per instance): 0x000 28 standard filters (1 word) 0x070 8 extended filters (2 words) 0x0B0 3 Rx FIFO 0 elements (18 words) 0x188 3 Rx FIFO 1 elements (18 words) 0x260 3 Tx event FIFO entries (2 words) 0x278 3 Tx buffers (18 words)

No acceptance filters are configured: every frame goes to Rx FIFO 0, the interrupt copies it into a software queue. Transmission uses the Tx FIFO.
