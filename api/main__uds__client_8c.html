Detailed Description

uds_client: UDS tester (ISO 14229 over ISO-TP) for nodes on iotwin-bus.

One-shot: uds_client scan uds_client –target gateway read 0200 0201 uds_client session extended + write 0103 012C Interactive: uds_client (commands from stdin; TesterPresent keeps a non-default session alive)

Single threaded except for the stdin reader in interactive mode: all bus traffic is handled by the main thread.
