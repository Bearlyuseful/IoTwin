Detailed Description

Calculation of CAN bit timing parameters from a controller clock.

A CAN bit is divided into time quanta (tq):

| SYNC (1 tq) | SEG1 = PROP + PHASE1 | SEG2 = PHASE2 | ^ sample point

bitrate = clock / (prescaler * (1 + seg1 + seg2)) sample point = (1 + seg1) / (1 + seg1 + seg2)

The calculation only accepts exact bitrates (no rounding error) and picks the solution closest to the requested sample point, preferring more time quanta per bit (finer resynchronisation). Portable C, unit tested on the host and used by the STM32 FDCAN driver.
