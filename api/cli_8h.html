Consumes the real-time and log options (–rt-priority N, –rt-cpu N, –rt-lock-memory, –log-level L) at argv[*index].

Returns
1 if the option was consumed (and *index advanced past its value), 0 if argv[*index] is not one of these options, -1 if the option was recognised but its value is invalid/missing.
