Detailed Description

IoTwin CAN gateway firmware for the NUCLEO-G0B1RE.

SLCAN over the ST-LINK virtual COM port (115200 8N1) <-> FDCAN1, plus a local node: user button = wall switch (0x200), LED = lamp command (0x100).
