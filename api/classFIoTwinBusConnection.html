Detailed Description

Worker thread that keeps a TCP connection to iotwin-bus alive and exchanges newline-terminated text lines with it.

  • Reconnects automatically while the bus is not reachable.
  • Incoming lines are queued for the game thread (DequeueLine).
  • Outgoing lines are queued by the game thread (EnqueueLine) and dropped while disconnected - like frames sent on an unconnected CAN node.
