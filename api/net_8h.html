Detailed Description

Minimal portable TCP socket layer (POSIX sockets / Winsock2).

Only what the bus server and the simulators need: connect, listen, accept, send/recv, non-blocking mode and poll. On POSIX SIGPIPE is ignored by net_init(), so writing to a closed peer returns an error instead of killing the process.
