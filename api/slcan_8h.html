Detailed Description

SLCAN (Lawicel CAN232/CANUSB) ASCII protocol used on serial links.

Commands are terminated by a carriage return. The adapter answers with CR (ok) or BEL (0x07, error). Frames use the same syntax in both directions:

t1232DEAD standard frame, id 0x123, DLC 2, data DE AD T1F3344551AA extended frame, id 0x1F334455, DLC 1 r1230 standard remote frame, DLC 0 R1F3344552 extended remote frame, DLC 2

Supported commands: O (open), L (listen only), C (close), S0..S8 (bitrate), V (version), N (serial number), F (status flags), Z0/Z1 (timestamps, accepted but ignored). IoTwin extensions: l (open in internal loopback mode) and Q (statistics). Portable C without libc formatting, used by the host bridge and the STM32 firmware.

Typedef Documentation

◆ SlcanLineCallback

typedef void(* SlcanLineCallback) (const char *line, size_t length, void *user_data)

Called for each complete line (NUL terminated, without terminator).

An empty line is a plain CR, i.e. an "ok" answer. A BEL byte is reported as the one-character line "\a" (error answer); BEL needs no terminator.
