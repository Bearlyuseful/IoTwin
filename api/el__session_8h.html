Detailed Description

Transport-independent interface of the electrical simulation (ADR 0008).

A session runs one installation: commands go in, snapshots (the complete electrical state after a step) and events (trips, rejected commands) come out. Every adapter - in-process (the Unreal visualizer), shared memory or network - only moves these three things.

Threads: one thread sends commands, one simulation thread calls el_session_step(), one reader thread takes snapshots and events (sender and reader may be the same thread). The queues and the snapshot exchange are lock-free and wait-free, so a real-time simulation thread never waits for a slow reader such as a game engine frame; the reader always gets the newest complete snapshot. The simulation thread does not allocate memory after the first step.

The topology (devices, terminals, connections) is fixed for the lifetime of a session; a changed installation means a new session.
