Detailed Description

can_sim: simulated light control ECU on the IoTwin CAN bus.

Threads:

  • main thread: cyclic control loop (optionally real-time), owns the socket
  • console thread: reads commands from stdin (not real-time)

The control loop never blocks on the network while connected: it reads whatever arrived, runs the ECU step, sends the outputs and sleeps until the next absolute deadline.

Diagnostics: UDS server on 0x7E0/0x7E8 (functional 0x7DF), faults can be injected on the console (see light_ecu_diag.h, docs/dev/diagnostics.md).

Test bench: the simulator registers on the bus as "--name" (default "ecu") and executes test bench lines "@ecu <console command>" sent by can_scenario (see docs/dev/scenarios.md).
