Detailed Description

Connects the game to iotwin-bus and makes the CAN traffic available on the game thread. Configure in DefaultGame.ini ([/Script/IoTwin.IoTwinBusSubsystem]) or per run with -IoTwinBusHost=, -IoTwinBusPort=, -IoTwinBusDisabled.
